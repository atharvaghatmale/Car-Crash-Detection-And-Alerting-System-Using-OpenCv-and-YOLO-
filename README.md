# 🚗 Crash Detection and Alerting System using OpenCV and YOLO

This project implements a **real-time, software-only vehicle crash detection and alerting system** using **YOLOv8**, **OpenCV**, and **Deep Learning**.

## 📌 Project Overview
Road accidents require fast and accurate detection. This project provides a low-cost AI solution capable of detecting crashes from live video feeds.

## 🧠 Key Features
- Real-time crash detection  
- YOLOv8-based vehicle tracking  
- CNN-based crash classification  
- Automated email/SMS alerts  
- High accuracy and low latency  

## 🛠️ Tech Stack
- Python  
- YOLOv8  
- OpenCV  
- TensorFlow / PyTorch  
- SMTP / Twilio

## 🚦 System Workflow
1. Video Input  
2. Frame Extraction  
3. YOLO Detection  
4. Crash Classification  
5. Alert Trigger  
6. Notification to emergency services  

## 📈 Results
- Precision: **100%**  
- mAP@50: **98.77%**  
- mAP@50-95: **91%**
